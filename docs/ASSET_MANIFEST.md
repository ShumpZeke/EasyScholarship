# Asset Manifest

This pack contains generated placeholder assets for the Easy Scholarships premium auth experience.

## Drop-in path
Copy this folder into the app:

`public/auth-assets/`

## Main generated assets

| File | Purpose |
|---|---|
| `logo-light.svg` | Wordmark for dark backgrounds |
| `logo-dark.svg` | Wordmark for light contexts |
| `logo-mark.svg` | Standalone icon/mark |
| `favicon.svg` | Browser icon placeholder |
| `student-hero.jpg` | Desktop hero/background placeholder |
| `campus-bg.jpg` | Alternative background placeholder |
| `dashboard-preview.png` | Abstract dashboard preview |
| `resume-preview.png` | Abstract resume scan preview |
| `gold-texture.png` | Gold surface texture |
| `noise-texture.png` | Subtle noise tile |
| `grain-overlay.png` | Transparent film grain overlay |
| `gold-particle-overlay.png` | Transparent gold particle overlay |
| `profile-1.jpg` to `profile-3.jpg` | Placeholder profile images |
| `reference-images/*.png` | Visual concept/reference frames |
| `ui-mockups/*.png` | Login/signup/forgot-password UI reference mockups |
| `3d/scholarship-core.glb` | Main 3D core model placeholder |
| `3d/scholarship-core-draco.glb` | Same model copied under expected compressed filename placeholder |
| `3d/opportunity-capsule.glb` | Capsule model placeholder |
| `3d/floating-scholarship-card.glb` | Floating card model placeholder |
| `3d/*.obj` | OBJ fallback versions |

## Notes
- These are original generated placeholder assets.
- Replace them with final brand art when available.
- The `scholarship-core-draco.glb` file is not truly Draco-compressed. It exists so developers have the expected filename during early implementation.
