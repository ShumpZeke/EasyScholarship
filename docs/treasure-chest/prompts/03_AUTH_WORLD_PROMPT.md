# Auth Pages in the Treasure World

Update login, signup, and forgot-password so they match the treasure chest world.

## Visual direction
- dark glass or metal form cards
- muted gold trim
- smoky background
- subtle treasure particles
- small chest or gold glow in background
- smooth entry animation

## Do not use
- generic white cards
- plain centered form with no atmosphere
- hard-cut navigation

## Keep functionality
Do not break existing Supabase or auth logic.
Only restyle and wrap with cinematic transitions unless auth code must be fixed.

- Login
- Signup
- Forgot password
