# Treasure Chest Model Generation Prompts

Use these if the uploaded GLB needs replacement or enhancement.

## Meshy / Tripo / Rodin prompt
A highly detailed realistic fantasy-luxury treasure chest for a premium scholarship website hero. Dark aged wood panels, brushed gold metal bands, ornate hinges, realistic bevels, engraved trim, functional lid, thick structure, metal latch, subtle scratches, worn edges, PBR materials, high-quality textures, openable lid, inside filled with gold coins, gems, crystals, pearls, scholarship cards, warm golden light source inside, cinematic but not cartoon, web-ready GLB, clean topology, separate lid object, separate treasure objects, named nodes, animation clip for opening lid.

## Negative prompt
cartoon, toy, low poly, too bright, neon, plastic, childish, pirate logo, skulls, weapons, unreadable text, messy topology, fused lid, non-openable chest, excessive polygons, horror, gore

## Blender refinement checklist
- Separate lid from base
- Name lid node clearly: `chest_lid` or `top_01`
- Add bevels to catch light
- Apply transforms
- Clean topology
- Reduce unnecessary geometry
- Bake AO if useful
- Assign PBR materials
- Export GLB
- Test animation in Blender before export

## Substance/PBR texture checklist
- base color
- metalness
- roughness
- normal
- ambient occlusion
- emissive map for glow if needed

## Export rule
Use GLB with named nodes and clean animation clips.
