# Remotion Treasure Chest Teaser Prompt

Create a Remotion composition named `TreasureChestTeaser`.

## Specs
- 8 seconds
- 24 fps
- 1920x1080
- cinematic dark/gold palette

## Sequence
0s to 1.5s:
Wide landscape. Treasure chest closed in the distance.

1.5s to 3s:
Camera moves closer. Gold reflections flicker on chest metal.

3s to 4.5s:
Chest latch glows. Dust particles rise. Lid vibrates slightly.

4.5s to 6.5s:
Lid opens. Warm light spills out. Coins and gems become visible.

6.5s to 8s:
Camera zooms into the open chest. Scholarship cards hover above gold and gems.

## Assets
Use included legacy video only as timing reference. Final object must be a treasure chest.
