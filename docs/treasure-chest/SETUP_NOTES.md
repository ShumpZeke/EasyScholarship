# Setup Notes

## Suggested packages
Install if missing:

```bash
npm install three @react-three/fiber @react-three/drei framer-motion
npm install three-stdlib meshoptimizer leva
npm install -D @gltf-transform/cli
```

Optional:

```bash
npm install gsap
npm install lenis
npm install @remotion/cli remotion
```

Only add optional packages if they solve a real problem.
