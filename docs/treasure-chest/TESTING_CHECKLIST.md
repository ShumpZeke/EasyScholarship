# Testing Checklist

Run:

```bash
npm run build
npm run lint
```

If scripts do not exist, report that clearly.

Manual checks:
- homepage loads
- scroll animation works
- chest opens
- gold/coins/gems appear
- route transitions animate
- login page does not hard-cut
- signup page does not hard-cut
- forgot password page works
- dashboard route works
- mobile layout works
- reduced motion works
- keyboard navigation works
- no white flashes
- no horizontal overflow
- no console errors
