# Image and Video Generation Prompts

Use these prompts in Nano Banana Pro 2, Midjourney, Imagen, Flux, Runway, Sora, Kling, Pika, Veo, Luma, or any similar image/video tool.

Do not add text inside generated images. Do not use public figures. Do not copy igloo.inc or any protected brand assets.

## Shared visual DNA
Palette: #0D0D0C, #151410, #1B1A16, #D8B45A, #F1D98A, #F8F1DC. Materials: smoked glass, brushed muted gold, anodized graphite, soft cream light, faint grain. Mood: quiet luxury, premium student-finance technology, cinematic but calm.
