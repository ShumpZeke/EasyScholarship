# Asset Notes

## Current assets

The ToolBox includes:

- original vault scroll video
- two reference screenshots
- start and end poster frames
- 24 extracted frames from the video
- one contact sheet for quick visual review

## Why extracted frames are included

The extracted frames help Claude Code understand the scroll sequence without needing to inspect the whole video manually. They also help debug the scroll mapping.

## How to improve assets later

Recommended improvements:

- Create a longer 12-16 second vault video for smoother scroll control.
- Render at 1920x1080 or 2560x1440 for sharper desktop display.
- Make the final open state hold for at least 2 seconds.
- Add a version with no text so the website UI can be cleanly overlaid.
- Add a transparent particle overlay video for dust, sparks, or gold glow.
- Export a mobile crop version of the video.

## File naming rule

Keep names simple:

- `vault-scroll-background.mp4`
- `vault-scroll-background-mobile.mp4`
- `poster-start.png`
- `poster-end.png`
- `vault-open-reference.png`
- `vault-closed-reference.png`
